# AnyPDF — what changed in 0.7.29

Every connected user can now add supplied signature images to their own completed IMM5476 and download a signed, scanned-style PDF. Review each signer, image and date and obtain the human's approval before signing. The original unsigned fill stays separate; signing does not submit anything to an issuing authority.
