# What's new in this version

This release lets you change saved packing rules in this chat. Say the new rule, confirm the readback, and it is saved. You do not edit files or run commands yourself. First-session orientation stays in place: the agent briefly explains what AnyDoc does before your first packing job. After a version bump it reads these notes, tells you what changed, and resumes your prior request without making you repeat it. AnyDoc continues to use the shared Jacky login and Tell-Jacky feedback experience used across official plugins. You still confirm the packing list before files are written. You still verify the finished package matches what you approved.
