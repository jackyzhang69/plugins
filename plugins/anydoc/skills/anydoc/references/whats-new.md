# What's new in this version

This release lets the agent connect with Jacky's assistant using a join code, so inspect and assemble status can be checked live without sending your files. First-session orientation stays in place: the agent briefly explains what AnyDoc does before your first packing job. After a version bump it reads these notes, tells you what changed, and resumes your prior request without making you repeat it. AnyDoc continues to use the shared Jacky login and Tell-Jacky feedback experience used across official plugins. Sign-in and account checks follow the same pattern as other Jacky products when you need saved assembly models. Packing, inspection, and assembly behavior is unchanged in intent. You still confirm the packing list before files are written. You still verify the finished package matches what you approved.
