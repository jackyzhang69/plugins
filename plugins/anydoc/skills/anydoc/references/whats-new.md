# What's new in this version

PDF compression now defaults to clarity priority: before anything is shrunk, you hear the worst-case size and quality floor, and AnyDoc will not go below that floor just to hit a file-size limit. If the floor file is still too big, that is called out instead of looking like a normal finished package. You can still change saved packing rules in this chat—say the new rule, confirm the readback, and it is saved without editing files yourself. First-session orientation still briefly explains AnyDoc before your first packing job; after a version bump the agent reads these notes, tells you what changed, and resumes without making you repeat. Shared Jacky login and Tell-Jacky feedback stay in place. You still confirm the packing list before files are written, and verify the finished package matches what you approved.
