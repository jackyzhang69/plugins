# Public CLI command paths (coverage reference)

`"$ANYCASE_BIN" commands --json` and translate it for the human.

`policy`, `manual`, `pnp`, `coverage`, `notes`, `knowledge`, `query`, `feedback`, `commands`,
`check-eligibility`,
`pair join`, `pair status`, `pair snapshot`, `pair inbox`, `pair read`,
`pair result`, `pair close`.
