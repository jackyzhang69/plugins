# What's new in 1.9.11

Updating the plugin now leaves exactly one clean copy, with no old versions or leftover files kept around.
Your login, settings and case data are not touched by an update.
FormBro now tells you at most once a day when a newer version is available, and only after finishing your request.
It never updates itself without your agreement.
Reading RCIC profiles is now explained more clearly: a profile list shows who the RCIC is, never the portal password.
Portal credentials are managed in the FormBro settings, and web-form filling uses them automatically when a portal needs them.
Every command in the plugin now has a plain description, so the assistant picks the right one more reliably.
