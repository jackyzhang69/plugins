# What's new in AnyKnow 0.1.22

AnyKnow now checks once a day whether a newer version exists and prints a short notice when one does.
The notice never blocks a request, and you tell the person about it once after finishing their task.
After an update, the plugin cleans up by itself and leaves exactly one installed copy, with no backup of the old one.
A new repair step does the same cleanup on demand and keeps the login, settings and saved knowledge untouched.
Every command now carries a plain one-line description, so the command list explains itself.
Saving, searching, exporting and support sessions behave as before.
