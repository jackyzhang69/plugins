# What's new in AnyWrite 0.1.9

AnyWrite now checks once a day whether a newer version exists and prints a short notice when one does.
The notice never blocks a request, and you tell the person about it once after finishing their task.
After an update, the plugin cleans up by itself and leaves exactly one installed copy, with no backup of the old one.
A new repair step does the same cleanup on demand and keeps the login, this computer's approval and every saved writing method untouched.
Every command now carries a plain one-line description, so the command list explains itself.
Teaching, writing, saving, revising and exporting writing methods behave as before.
