# What's new in 0.1.71

On Windows, WeChat version detection reads executable metadata directly to prevent misclassification. When WeChat is not running, AnyChat correctly reminds users to open and log in to WeChat instead of reporting that a pinned version is required. Multi-shard Windows archives now scan until all database shards are unlocked. Saving notes and linking identities requires explicit confirmation, while topic saving directly creates the topic using the proposed name when not specified.

# What's new in 0.1.70

On Windows, AnyChat continues as soon as the chat app is open, including on its login screen; complete sign-in there if it asks. First-time local access spends less time on the same material twice and checks the live message database first. Voice files can be downloaded; turning them into Chinese or any other text is done by your assistant, not AnyChat.
