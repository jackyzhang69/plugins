# AnyChat 0.1.78

## User-visible changes

- After a partial archive is already usable, you can ask AnyChat to finish scanning the remaining chat-history parts. If that extra scan cannot finish, the already-usable archive stays usable; AnyChat will say some parts are still incomplete.
- After install guidance, AnyChat checks that the installer package, the installed app, and the running app are the same version. If they disagree — for example after only opening the installer image — setup waits until the replacement is finished and the app is reopened.
