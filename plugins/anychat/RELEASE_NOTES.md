# AnyChat 0.1.75

## User-visible changes

- First-time Windows setup now searches long enough to finish, and keeps going on the parts that were not done yet instead of stopping because the clock ran out.
- If some chats on this computer are already readable, AnyChat can open them even when the rest of the archive is still incomplete. The result will say what is missing.
- Setup failure messages now reach you as they are. A normal English sentence is no longer treated as a command.
