# AnyChat 0.1.98

On Windows, after the supported chat app is installed, pausing automatic replacement no longer stops setup. If Windows asks for Allow, click it and continue. A missing updater folder or a chat app that is not running is not a dead end.

On Windows, a picture that still needs a local key no longer reports ready after the computer permission was already allowed. That false ready was what asked for the same permission again. Picture keys for the current Windows chat app can be recovered from this computer's account data, including the raw 16-byte form used by 4.1.9.

Checking status, resolving a name, and previewing a note to Jacky return within a short window with a next step instead of sitting silent. When chat history is usable but still incomplete, status says a remaining-history scan is needed.

On Windows, a picture already saved in this chat's bubble or thumbnail cache is found even when the attachment folder is empty. A picture from a different chat is not returned in its place.
