# AnyChat 0.1.70

## User-visible changes

- On Windows, opening the chat app no longer delays AnyChat until after sign-in. If a login screen is showing, complete it there; AnyChat already continues.
- First-time local access spends less time repeating the same material and checks the live message database first.
- Voice files can be downloaded as playable audio. Turning voice into Chinese or any other text is done by your assistant, not by AnyChat.
