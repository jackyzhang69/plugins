# AnyWeb — what changed in this version

This package can fill a supported Express Entry profile on your computer up to
the last review before submit. Give your applicant files first; the assistant
compiles one pack, AnyWeb checks it without opening a page, then logs in and
fills, you do not type into the website, and a wrong-shaped pack is fixed or
a missing fact is asked once; it will not invent answers or quiz you one
website field at a time. Email codes pause so you can give them to this
assistant; the program types them and continues. If the first code does not
take, it resends on the same page and asks for the new one; it does not log
in again. You can save a website login
for this computer using the ordinary Express Entry login. If a step cannot
run, AnyWeb says so in plain words and does not pretend the request arrived
when it was refused. Feedback is only treated as delivered when the product
confirms it reached the service, not when it exists only on your machine. A
repair that is available is not permission to submit.
