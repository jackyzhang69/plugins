# AnyWeb — first session orientation

AnyWeb fills one supported Express Entry profile on this computer, in visible
Chrome, and stops before the last Continue or submit. Give it the applicant's
information files first. The assistant compiles those files against the
product schema into one complete pack, AnyWeb checks the pack without opening
a page, and only then logs in and fills. It does not invent answers, it does
not quiz you field by field, and it does not file the application. You do not
type into the website.

On a first session, start that fill from the files. Email codes pause so you
can give them to this assistant; the program types them and continues. If the
first code does not take, it resends on the same page instead of logging in
again. You can save a website login for reuse on this computer; saved
secrets never appear in chat. You authorize any irreversible action. AnyWeb
reports state rather than claiming submission.

Repair-claim checks and a Jacky pair session exist if you need them; they are
not the starting product.
