# AnyWeb official plugin

AnyWeb fills one supported Express Entry profile on this computer, in visible
Chrome, and stops before submit. Give the applicant information files first;
the assistant compiles one complete pack and AnyWeb runs it. It also lets you
save a website login for reuse here, send Jacky a note, and check a repair
claim if you need one. Website work stays on this computer. A saved login and static security answers
require explicit setup and can be replaced or forgotten without a reveal or
export command. The package does not bundle private site knowledge, fixtures,
client values, or a general website runner.

The fill fails closed on ambiguous drafts and never performs the final
Continue or submission.
