# AnyMail — first session orientation

AnyMail is a private agent-native mail client for Gmail and Microsoft accounts
you authorize in the official browser. It can search and read mail, download
bounded attachments, keep local drafts, show an exact send preview, and send
only after a one-time confirmation. It does not ask you to paste tokens, create
OAuth apps, or install another mail client. Machine work such as discovery stays
silent unless something truly needs your judgment.
