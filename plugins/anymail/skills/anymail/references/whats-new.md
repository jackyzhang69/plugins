# AnyMail — what changed in 0.1.15

Updating AnyMail through Claude Code now completes: the final repair step no longer stops on a marker folder Claude Code adds to its plugin cache. Installing or updating AnyMail leaves only the current version on your computer. The previous copy is no longer kept, and your sign-in, mailboxes and drafts are untouched. AnyMail can now tell your assistant when a newer version is available. The reminder comes at most once a day, never delays your mail work, and nothing is installed until you agree.
