# AnyMail — what changed in 0.1.11

Gmail sign-in that comes back without your identity or Gmail permission now says the grant was incomplete, while a real identity mismatch is still refused. Reauthorizing the same Gmail account after an AnyMail update that changes the Google sign-in app now keeps that account, its sender address, and local drafts. Outlook and Microsoft 365 word search works again, including unread-only search, and search failures say how to recover. The install check now names which AnyMail is running and whether the installed copy matches, so a missing or older install is not treated as a broken client. Before you add Gmail send permission, AnyMail explains that Google may show an unverified or unsafe warning. Draft create, reply, forward, and update now name the exact wrong field instead of a general schema error. Feedback create now shows the draft for review first when you have not confirmed it yet. This 0.1.11 Windows client is unsigned by owner waiver; macOS stays signed and notarized.
